Builder
=======

:class:`~edify.RegexBuilder` is the fluent, immutable builder; every method
returns a new builder. :class:`~edify.Pattern` shares the same building surface
and is additionally callable as a validator and reusable with
:meth:`~edify.RegexBuilder.use`.
