Guide
=====

Edify builds regular expressions the way you'd describe them out loud. This
guide walks the whole surface from the ground up — every anchor, character
class, quantifier, group, and assertion — then the batteries around the builder:
the validator library, introspection, serialization, and framework integrations.

Read it top to bottom the first time; each topic builds on the last. Come back
to any single page as a reference later.
